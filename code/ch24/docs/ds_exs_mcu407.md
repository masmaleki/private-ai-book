# EXS-MCU407-LQFP100 32-bit Microcontroller

## Overview
32-bit core at 168 MHz, 1 MB flash, 192 KB RAM, LQFP-100 package.
Supply voltage 1.8 V to 3.6 V. Operating temperature -40 °C to 85 °C
(industrial) or -40 °C to 105 °C for the -T variant.

## Peripherals
3 x 12-bit ADC, 2 x CAN, 4 x USART, USB OTG full-speed, Ethernet MAC.

## Ordering
EXS-MCU407-LQFP100 (85 °C) and EXS-MCU407-LQFP100-T (105 °C). The two
variants are pin-compatible; check the temperature rating in the BOM.
