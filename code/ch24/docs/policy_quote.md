# Quoting guideline (internal, example)

Minimum gross margin on catalog parts is 12 %. For broker stock add a
quality-risk surcharge of 5 % and state the source in the quote. Never
quote broker stock to customers that require authorized sources only.
Quotes are valid for 14 days unless the supplier offer expires earlier.
