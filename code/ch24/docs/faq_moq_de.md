# Häufige Fragen: Mindestbestellmenge (MOQ) und Lieferzeit

Wie hoch ist die Mindestbestellmenge? Für Reel-Ware gilt meist eine volle
Rolle, zum Beispiel 2.500 Stück bei SO-8. Teilmengen sind über Cut-Tape
möglich, aber teurer.

Wie lange ist die Lieferzeit? Lagerware wird innerhalb von 2 Arbeitstagen
versendet. Bei Werksbestellung beträgt die Lieferzeit oft 12 bis 20 Wochen.
