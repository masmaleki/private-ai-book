EXS-BUCK36-SO8 from Example Semiconductors is a fictional step-down (buck)
converter in an SO8 package. Input voltage range is 4.5 V to 36 V. Maximum
output current is 3 A. Switching frequency is fixed at 500 kHz.

Operating temperature range is -40 C to 125 C. The part has an enable pin
and internal soft start. Lifecycle status in this example is active.
