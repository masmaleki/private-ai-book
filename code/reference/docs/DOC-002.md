EXS-LDO500-33 is a fictional low-dropout linear regulator with a fixed 3.3 V
output and up to 500 mA output current. Package is SOT223.

Dropout voltage is 0.35 V at 500 mA. An LDO wastes the voltage difference as
heat, so for large input-output differences a buck converter is preferred.
