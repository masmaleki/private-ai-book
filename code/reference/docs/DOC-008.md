STM32F407VGT6 is a public catalog microcontroller in an LQFP100 package. The
letter T before the last digit marks the package family and 6 marks the
industrial temperature range of -40 C to 85 C in this naming scheme. Always
check the current datasheet of the manufacturer before relying on a suffix.
